# Stories: kicking

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As Todd, I can define a chore that never runs on a schedule, only when
  I ask for it.
- As Todd, I can ask a one-time chore to start now, and see it running
  within moments.
- As Todd, I can ask a one-time chore to start at a time I name, and see
  it waiting until then.
- As Todd, I can run the smoketest and find out within a few minutes
  whether the herd works on this laptop, without waiting for any schedule.
- As Todd, I can see the smoketest's chores in the same history and on the
  same dashboard as every other run.
