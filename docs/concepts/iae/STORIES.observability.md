# Stories: observability

Watching the writing move toward "Green", and guardrails.

- As an author, I can monitor my writing the way an operator monitors a
  system.
- As an author, I can adjust what I see there and have the work respond.
- As an author, I can let AI influence the work toward the result I want.
- As an author, I can tell when the work is "Green": meeting all quality
  bars.
- As an author, I can see whether the work is consistent.
- As an author, I can see whether the work matches the narrative arcs I
  set.
- As an author, I can see whether the work is factually correct:
  characters have the right hair color, locations are described properly.
- As an author, I can see whether the work is emotionally and thematically
  correct: rising action where I want it, steamy where I want it.
- As an author, I can see the marks the AI reviewers gave the work.
- As an author, I can see whether the work stays on-tone and on-voice.
- As an AI reviewer, I give the work marks against the author's quality
  bars.
- As a technical writer, I have guardrails that make sure I don't make
  mistakes.
