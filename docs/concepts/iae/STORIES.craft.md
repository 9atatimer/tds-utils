# Stories: craft

The story-building tools around the prose.

- As an author, I can track plot.
- As an author, I can track tempo.
- As an author, I can track truths about characters.
- As an author, I can see a drama-visualization graph of the work -- the
  shape of the story, Vonnegut-style.
- As an author, I can keep knowledge bases, scene flow, dramatic notes,
  storyboards, and act structure for the work.
- As an author, I can fill any of those in by hand.
- As an author, I can have an AI help me fill any of those in.
