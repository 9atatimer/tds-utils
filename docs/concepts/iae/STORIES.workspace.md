# Stories: workspace

The IDE-shaped shell around the writing.

- As an author, I can open my whole authoring effort and navigate its
  files the way a programmer navigates a codebase.
- As an author, I can switch tabs across the top and have the left-hand
  panels change to match.
- As an author, I can see my AI agents in panels down the right-hand side
  while I write.
- As an author, I write in the middle in my favorite writing tool, not in
  one the IAE forces on me.
- As an emacs author, I can keep writing in emacs and still have the IAE
  around it.
- As a vi author, I can do the same in vi.
- As a Word author, I can do the same in Word.
- As an author, the thing open in my editor is a snippet, in a file my
  editor works on natively.
- As an author, my snippets can be LaTeX or plain text.
