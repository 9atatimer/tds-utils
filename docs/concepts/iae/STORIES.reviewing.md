# Stories: reviewing

From a red light to the offending page, the region, and the fix.

- As an author, I can view the editorial timeline, by page number, and
  see which pages are offending.
- As an author, I can drill into an offending page and see the offending
  regions on it.
- As an author, I can click an offending region and review the
  predicate's notes on why it failed.
- As an author, I can open a discussion about a region with one AI, or
  with several at once.
- As an author, I can engage copy-editor mode to strike through text and
  leave notes.
- As an author, I can engage author mode and write a revision.
- As an author, I can add a new snippet to a page, signal a revision of
  an existing snippet, or add a segue between snippets.
- As a copy editor, I strike through and annotate without rewriting.
