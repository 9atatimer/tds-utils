# Stories: access

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As Todd, I know that only my review runs can reach my laptop's model --
  nobody else on the internet can.
- As Todd, I know that whoever reaches my model can ask it to review code,
  and cannot change, pull or delete my models.
- As Todd, I can cut one owner off from my model without breaking the
  other. (Aspirational for the first cut, which shares one credential.)
- As Todd, I never have to paste a credential into a repo by hand more than
  once.
- As Todd, I know a PR's code is read by the review, never run on my laptop.
