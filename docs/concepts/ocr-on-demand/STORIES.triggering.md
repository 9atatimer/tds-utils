# Stories: triggering

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As Todd, I can ask for an `ocr` review of any PR in a 9atatimer repo
  whenever I want one.
- As Todd, I can ask for an `ocr` review of any PR in a Nine-At-A-Time-Media
  repo whenever I want one.
- As an LLM working on a PR, I can ask for an `ocr` review of it without a
  human in the loop.
- As Todd, I can ask for a review from the PR page itself, without leaving
  GitHub.
- As a stranger commenting on a public PR, I cannot make my comment start a
  review on Todd's model.
- As Todd, I can add the review to another repo without re-solving how it
  reaches my laptop.
