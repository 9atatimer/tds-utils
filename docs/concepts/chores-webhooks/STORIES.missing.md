# Stories: missing

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As Todd, I can close the laptop and know that the changes I miss are not
  silently lost: either they are caught up when it wakes, or I can see that
  they were missed.
- As Todd, I can see when the road was down, and for how long, on the same
  surfaces that tell me the scheduler is stale.
- As GitHub, I learn at once when the laptop is not there, instead of
  hanging.
- As Todd, I never see one change run the same chore twice because it was
  delivered twice.
