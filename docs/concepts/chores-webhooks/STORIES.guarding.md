# Stories: guarding

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As Todd, I know only GitHub, on behalf of my own repos, can make a chore
  run from outside -- nobody else on the internet can.
- As Todd, I know a change can only make a chore run; it can never define,
  change or delete one.
- As Todd, I know a chore fired by a change still spends within the same
  ceilings, budgets and breaker as every other chore.
- As Todd, I know text written by whoever pushed -- a branch name, a commit
  message, a PR body -- cannot steer what a chore does or spends.
- As Todd, I know a flood of changes cannot run up my spend or bury the
  laptop.
- As Todd, I know every credential on this road is managed as IaC in
  tds-internal -- none is made or pasted by hand.
- As Todd, I can turn off the road, or one repo's triggers, without
  touching anything else.
