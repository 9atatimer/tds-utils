# Stories: following

The herd keeping up as repos and their chores change.

- As an operator, I can add a repo's `.chores/` to my herd without
  copying anything into my own chore definitions.
- As an operator, I can see a repo's new or changed chores show up for
  acceptance without running a command to go and look for them.
- As an operator, I can see a removed repo chore stop being scheduled.
- As an operator, I can see which version of a repo's chores is running
  now, and which version is waiting for me.
- As an operator, I can switch branches, pull, or rebase a repo without
  the chores it runs changing underneath me.
- As an operator, I can delete or move a repo and see its chores stop,
  with their history kept.
- As an operator, I can see every run of a repo chore alongside my other
  chores' runs, in the same history and on the same dashboard.
