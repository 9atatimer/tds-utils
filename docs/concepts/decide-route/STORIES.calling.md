# Stories: calling

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As a local tool, I can ask a decision question in one place on the
  laptop and get every option's probability back.
- As a local tool, I can ask without holding any credential, and without
  1Password being unlocked.
- As a local tool, I can name the model I want, and I am told plainly when
  it cannot answer, rather than being answered by a different one.
- As a git hook, I learn at once when no decision is available, so I can
  decide for myself whether to block the commit.
- As a Python, shell or node tool, I ask the same way; nothing about the
  door is specific to one language.
- As `bin/decide`, I can point at the door and stop carrying the hosted
  plumbing myself.
