# Stories: finding

Standing on a PR page and learning which sessions made it.

- As a reviewer, I can tell from the PR page whether any of my tmux
  sessions is on this PR's branch, without leaving the page.
- As a reviewer, I can see how many sessions are on it, and for each,
  which agent, which clone or worktree, and whether it is still alive.
- As a reviewer, I can tell the difference between "no session" and "I
  cannot ask right now" (the machine-side half is not running).
- As a reviewer, I can see this on a PR I did not open, if one of my
  sessions happens to be on its branch.
- As a reviewer, I can see this for a PR whose branch came from a cloud
  session, and be told plainly that no local session exists for it.
- As a reviewer, I can see this on the PR list page, not only on one PR,
  so I know which of my open PRs still have a session behind them.
- As an agent, I do not have to do anything for my session to be found.
