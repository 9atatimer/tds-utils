# Stories: dashboard

The mac app on its own, without a PR page in front of me.

- As a reviewer, I can open the dashboard from the Dock or the menu bar
  and see my sessions grouped by PR.
- As a reviewer, I can see PRs of mine that have no session behind them,
  and sessions that have no PR yet.
- As a reviewer, I can see which sessions are attached and which are
  detached.
- As a reviewer, I can jump to a session from the dashboard, and open a
  PR from the dashboard.
- As a reviewer, I can see the same picture in a terminal as a TUI or as
  `--json`.
- As a reviewer, I can glance at the menu bar and know whether any of my
  PRs is waiting on me with a live session behind it.
- As the dashboard, I can tell the extension what it needs, and the
  extension never has to know how I got it.
