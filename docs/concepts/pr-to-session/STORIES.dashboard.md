# Stories: dashboard

The Mac-side view of what maps to what.

- As a developer, I can open a Mac dashboard and see my sessions with the
  repo and branch each is working on.
- As a developer, I can see which of my sessions have an open PR.
- As a developer, I can jump to a session from the dashboard.
- As a developer, I can go from a session in the dashboard to its PR on
  GitHub.
- As a developer, the dashboard is current without my refreshing it.
