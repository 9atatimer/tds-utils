# Stories: jumping

From a PR page back to the session that made it.

- As a developer reviewing a PR on GitHub, I can get back to the
  terminal session that produced it in one step.
- As a developer, I can see on the PR page whether any live session
  belongs to it, without asking.
- As a developer, when more than one session worked on the PR, I can see
  all of them and choose.
- As a developer, when the session is attached in another window, the
  right window comes forward.
- As a developer, when no session exists -- it ended, or the PR came from
  a claude.ai/code session -- I am told so, not left with a dead button.
