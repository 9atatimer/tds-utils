# Stories: jumping

The click that lands me in the terminal, on that session.

- As a reviewer, I can click once on the PR page and have Terminal come
  forward showing that tmux session.
- As a reviewer, when several sessions are on the branch, I can pick the
  one I want from the page.
- As a reviewer, when the session's window is attached somewhere, the
  jump switches that client rather than opening a second one.
- As a reviewer, when nothing is attached, the jump opens a new Terminal
  window attached to the session.
- As a reviewer, when there is no session, I am told so on the page and
  told why if it is knowable: cloud PR, session killed, branch renamed.
- As a reviewer, I can jump from the dashboard the same way I jump from
  the PR page.
- As a reviewer, I can go the other way: from a session, open its PR in
  the browser.
