# Stories: choosing

> Part of [CONCEPT.md](CONCEPT.md). Phase 1 -- not acceptance criteria.

- As an agent naming seams for a new component, I am told that a decision
  model is an option whenever the judgement has a bounded answer.
- As an agent, I can tell when a rule, a small fine-tuned classifier, a
  decision model, or a generative LLM is the right tool for a judgement.
- As Todd, I can see whether a decision model beats the model it would
  replace, on my own labelled examples, before I adopt it.
- As Todd, I can find decision models on the LMDE radar and know where they
  stand.
